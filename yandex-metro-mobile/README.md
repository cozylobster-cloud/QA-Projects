# Yandex Metro — Mobile App Testing

Functional and regression testing of the Yandex Metro Android application.

**Workbook:** [yandex-metro-mobb-app-testing.xlsx](./yandex-metro-mobb-app-testing.xlsx)

## Contents

- `1. Чек-лист (функциональное тес…)` — route and station functionality.
- `2. Чек-лист (регрессионное тест…)` — installation, upgrade, and existing features.
- `3. Баг-репорты` — defect reports.
- `Отчет о тестировании` — test environment and summary.

## Test Analysis Techniques

- Grouping functionality by route building, station selection, history, map, and settings.
- Identification of upgrade-related checks: APK installation, version upgrade, settings, and permissions.

## Test Design Techniques

- User scenarios for station input, tap selection, route history, and screen orientation.
- Positive and negative checks, including station selection with a setting enabled or disabled.
- Regression checklist for existing functionality after upgrading the application.

## Tools and Environment

- Android Studio emulator configured as Honor 8 with Android 9.0 Pie.
- XLSX checklists, defect reports, and test report.
