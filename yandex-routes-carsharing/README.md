# Yandex Routes — Carsharing Testing

Testing the car reservation interface, payment method, driver's license details, and Reserve button.

**Workbook:** [yandex-routes-carshearing-testing.xlsx](./yandex-routes-carshearing-testing.xlsx)

## Contents

- `1. Чек-лист на вёрстку` — reservation UI checks.
- `2. Чек-лист «Способ оплаты» и «…` — payment method and card forms.
- `2. Тест-кейсы на кнопку «Заброн…` — reservation button test cases.
- `Баг-репорты` — defect reports.

## Test Analysis Techniques

- Decomposition of the reservation form into plan selection, available cars, requirements, payment method, driver's license details, and reservation action.
- Analysis of required fields and conditions for completing a reservation.

## Test Design Techniques

- Checks with different combinations of filled and empty required fields.
- Positive and negative reservation scenarios.
- Checklists for UI states, payment actions, and car selection.

## Tools and Environment

- Yandex Browser and Firefox at the screen resolutions recorded in the UI checklist.
- XLSX checklists, test cases, and defect reports.
